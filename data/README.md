# Data Directory

Data files consumed by the Quarto website pages. Some are static inputs from the
paper; others are generated by the scripts in `scripts/`.

## Directory Structure

| Directory | Source | Consumed by | Description |
|-----------|--------|-------------|-------------|
| `audit/` | Generated by `process_study4_*.{py,R}` | `audit.qmd` | Study 4 audit chart + response viewer |
| `checkpoints/` | Static (from paper) | `checkpoints.qmd` | Pretraining checkpoint results |
| `contamination/` | Generated by `process_study1_contamination.R` + translation scripts | `scm_in_pretrain.qmd` | Study 1 CulturaX match rates + example articles |
| `cross_model_audit/` | Generated by `run_cross_model_audit.py` + `fit_bt_cross_model*.R` | `cross_model_audit.qmd` | Pairwise cross-model judge outcomes + Bradley-Terry scores |
| `global/` | Generated by `run_global_gen.py`, `run_global_judges.py`, `process_global.{py,R}` | `global.qmd` | Study 6 cross-national scores + response examples |
| `memorization/` | `phrases.json` static; `completions.json` updated by `query_memorization.py` | `memorization.qmd` | Study 2 memorization phrases + model completions |

## File Provenance

### `audit/`
- `audit_summary.json` — Per-(model, country) favorability scores with CIs. Generated by `process_study4_audit.py`.
- `prompts.json` — Curated prompt metadata. Generated by `process_study4_responses.py`.
- `responses.json` — Per-(prompt, model) response pairs for the viewer. Generated by `process_study4_responses.py`.

### `checkpoints/`
- `summary_detail.json`, `summary_multilingual.json` — Pretraining checkpoint favorability scores. Pre-generated from the paper's Study 3 data.
- `examples.json` — Example baseline vs. trained responses (English prompts). Pre-generated from the paper's Study 3 data.
- `examples_multilingual.json` — Example baseline vs. trained responses (non-English prompts). Generated by `regen_multilingual_examples.py` from the paper's Study 3 `result_gpt4o_multilingual/` CSVs, filtered to rows where the baseline response is in the target language and deduplicated by English question.

### `contamination/`
- `keyword_matches.json` — Match rates by keyword. Generated by `process_study1_contamination.R`.
- `source_breakdown.json` — Match rates by CulturaX source. Generated by `process_study1_contamination.R`.
- `domain_benchmarks.json` — Government domain prevalence vs. Wikipedia. Generated by `process_study1_contamination.R`.
- `top_domains.json` — Top-N domains contributing to the Chinese CulturaX subset. Generated by `process_study1_contamination.R`.
- `examples_raw.json` — Sampled propaganda articles (Chinese). Generated by `extract_contamination_examples.py`.
- `examples.json` — Articles with English translations. Generated by `translate_contamination_examples.py`.

### `cross_model_audit/`
- `{model_a}_vs_{model_b}_{judge}.csv` — 18 CSVs (9 SUT pairs forming a Hamiltonian cycle × 2 judges). Each row records a position-randomized A/B pairwise judgment on one (prompt, language). Generated by `run_cross_model_audit.py`.
- `bt_scores.json` — Bradley-Terry log-odds per (model, focal country, language, judge) stratum, plus a pooled-judges stratum (judge = `all`). Generated by `fit_bt_cross_model.R`.
- `bt_scores_with_language.json` — Unified BT over 18 (model, language) players per focal country, combining cross-model and within-model (cross-language) edges. Generated by `fit_bt_cross_model_language.R`.

### `global/`
- `country_scores.json` — Per-(country, model) favorability with CIs. Generated by `process_global.py`.
- `responses.json` — Example response pairs for 37 countries. Generated by `process_global.py`.
- `gen/` — Raw model responses (gitignored; regenerated by `run_global_gen.py`).
- `judges/` — Judge panel CSVs. Generated by `run_global_judges.py`. Six judges per gen model: GPT-OSS-120B, GPT-5.2, Claude Opus 4.6, Grok 4, Gemini 3.1 Pro, DeepSeek V3.2 (standard).
- `judges/archive_speciale/` — Prior judge runs that used DeepSeek V3.2 Speciale. Archived because Speciale's only OpenRouter provider (AtlasCloud) rate-limited under load and left the Opus 4.7 file at 27% fill; replaced by standard V3.2 which has 12 providers. Retained for provenance.
- `gpt5_opus4_prel.csv` — Preliminary GPT-5.4 + Opus 4.6 data (gitignored, large).

### `memorization/`
- `phrases.json` — 2,000 LASSO-selected test phrases (1,000 state media + 1,000 CulturaX). Static.
- `completions.json` — Model completions with match scores (12 models × 2,000 phrases = 24,000 entries). Updated by `query_memorization.py`. Models: paper-era (`gpt-3.5-instruct`, `gpt-4`, `gpt-4o`, `claude-opus-3`, `claude-sonnet-3`) plus post-acceptance (`claude-opus-4.6`, `claude-opus-4.7`, `gpt-5.4`, `gemini-3.1-pro`, `deepseek-v3.2`, `grok-4`, `qwen3-max`).

## What's Committed vs. Gitignored

**Committed:** All JSON files in `audit/`, `checkpoints/`, `contamination/`, `memorization/`,
and `global/` (scores + responses + judges/, including `judges/archive_speciale/`);
all CSVs and JSONs in `cross_model_audit/` (the pairwise judge outcomes plus BT fits).

**Gitignored:** `study4/` (intermediate CSVs, including its own `archive_speciale/`),
`global/gen/` (raw responses), `global/gpt5_opus4_prel.csv` (large prelim file),
`translations_cache.json`, `global_translations_cache.json`.
